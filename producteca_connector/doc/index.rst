Odoo Producteca Connector
========================

Installation
------------

1. Install the Producteca Connector module from the Odoo App Store:

.. image:: images/install_app.png
   :alt: Install from Odoo App Store
   :width: 600px

Configuration
------------

1. Create a new Producteca account if you don't have one yet

2. Get your API credentials from Producteca:
   
   * Go to your Producteca account settings
   * Navigate to the API section
   * Copy your API Key and Token

3. Configure the Producteca Connector in Odoo:

   * Go to Settings > Producteca
   * Enter your API Key and Token
   * Click Save to validate the connection

Now you're ready to start synchronizing your products between Odoo and Producteca!
