Producteca en tu odoo

¿Qué es Producteca odoo conector?

Es el Conector No Oficial de Producteca para Odoo (módulo odoo_conector_api_producteca), diseñado para conectar marketplaces.

  • Desarrollado por: Chroma Agency

Características

  • • Publica productos/precios/stock completos desde Odoo.
  • • Enlace de imágenes y variaciones de atributos.
  • • Actualización automática de precios y stock.
  • • Soporte para múltiples ubicaciones y compañías.
  • • Sincronización de stock por compañía.
  • • Recibe pedidos, clientes e información de envío.
  • • Importa órdenes de venta de cada canal.
  • • Importa direcciones de facturación y entrega.
  • • Usa el código Odoo como SKU para encontrar productos.
  • • Gestiona notificaciones y facturas.
  • • Notificaciones internas para sincronización de stock y precios.
  • • Notificaciones por nuevo pedido importado.
  • • Las facturas se crean y se envían a Producteca.

Configuración sencilla y rápida

El módulo está diseñado para una instalación y configuración simple directamente desde el panel de Odoo.
